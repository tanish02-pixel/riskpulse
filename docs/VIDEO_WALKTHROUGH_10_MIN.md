# Recorded walkthrough - ten-minute flow

The five-minute live demo and the recorded walkthrough are different deliverables. The provided submission screenshots described a ten-minute recorded walkthrough. Confirm the exact allowed video length in the current organizer guidelines before uploading.

This package contains a script, not a recorded application video. Record the working application on your laptop with your own narration.

| Time | Content |
|---|---|
| 0:00-0:45 | Name/team, project, challenge, selected Module A |
| 0:45-1:45 | Architecture slide, two source types, backend/dashboard separation |
| 1:45-2:45 | Live sources, fetch status, publication times, one actual signal |
| 2:45-4:15 | Synthetic replay, positive/negative examples, three required output fields |
| 4:15-5:45 | Baseline/current allocation, history, total 100%, weight and turnover constraints |
| 5:45-6:45 | Signal evidence, entity mapping, confidence, severity calculation |
| 6:45-7:30 | Text preview, optional CSV import, JSON export, API schema |
| 7:30-8:30 | Repository layout and exact setup commands from README |
| 8:30-9:15 | Measured tests and synthetic evaluation, explicit limitations |
| 9:15-10:00 | AI disclosure, proposed real-news evaluation/backtesting, closing demonstration |

## Recording steps

1. Finish setup and confirm FinBERT is active. Inspect the dashboard on your laptop first.
2. Rehearse once with the timer. Reset replay before the recorded run.
3. Use a screen recorder such as the system recording tool or your existing recorder. Capture the browser and microphone. Hide unrelated personal tabs and notifications.
4. Show real clicks and actual responses. If a source fails, describe the failure and use the labeled replay.
5. Review the recording for readable charts and clear audio. Ensure it fits the current organizer limit.
6. Upload using the access mode the organizer requires. If YouTube is specified, an unlisted link can be accessible without listing the video publicly. Confirm anyone with the link can play it signed out.
7. Put the final video URL in `SUBMISSION_TEMPLATE.txt`, your README submission information, and the submission portal. Do not submit placeholders.
