Project: RiskPulse - Financial Risk Intelligence and Index Rebalancing
Selected downstream application: Module A - Tactical Index Rebalancing

RiskPulse implements a unified AI/NLP risk engine that ingests financial news and first-party company announcements. It outputs sentiment score, event classification, and impact score through a REST API and JSON/CSV export. FinBERT provides sentiment when configured, while auditable rules provide event categories and an uncalibrated severity estimate.

Module A rebalances a mock ten-stock index using fresh, eligible company sentiment. The dashboard shows current weights, baseline comparisons, persisted history, signal evidence, data-source status, and configurable weight/turnover constraints. Live feeds and clearly labeled synthetic replay use separate portfolios. The repository includes datasets, setup instructions, tests, and an AI assistance disclosure.
